ICE Challenges

Apostles Spotlight

This assignment shows all of the current 12 Apostles as well as the current Presidency of the Church. I learned how to use a grid to align all items on the page as well as manipulating photos to be a certain size and shape.

Favorite Devotionals

In this assignment I learned how to use tables to organize information on a page. Each devotional was organized by Speaker, Title, Location, and Year. I also learned to create entry boxes to enter in information.

Halloween

This assignment was all about working with CSS. We learned how to manipulate a webpage without changing any of the html elements.

Prophet Card

This project taught me to align elements on a page within a grid. It was difficult figuring out how to align text and an image within a grid without anything overlapping.

Country Flags Page

While making this page I learned how to make div and nav tags in html to create country flags. From these tags I changed their background colors to make the shapes of the flags.

Social Card

In this ICE Challenge I learned how to use Icons by making a social media card with different icons to complete it.
